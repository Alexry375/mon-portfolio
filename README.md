## Installation & développement

Assurez-vous d'avoir nodejs `19.9.0` ou supérieur et npm `9.6.3` ou supérieur installés. Installez les dépendances avec :

```bash
npm install
```

Lancez le serveur de développement :

```bash
npm run dev
```

Pour visualiser le storybook des composants :

```bash
npm run dev:storybook
```

## Déploiement

### GitHub Pages

Ce portfolio est déployé sur GitHub Pages. Pour déployer :

1. Build le projet :
```bash
npm run build
```

2. Configurez GitHub Pages dans les paramètres du repository (Settings > Pages)
3. Sélectionnez la branche et le dossier de build
4. Le site sera disponible à l'URL fournie par GitHub Pages

### Déploiement automatique

Vous pouvez configurer GitHub Actions pour déployer automatiquement à chaque push sur la branche principale.
